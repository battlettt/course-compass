# Project Management

## Planning a project

A project is planned by breaking the work into activities, estimating how long each takes, and recording which activities must finish before others can start. These precedence relationships are drawn as a network diagram.

## Key terms

- **Work breakdown structure**: a hierarchical decomposition of the total project scope into smaller, manageable work packages.
- **Critical path**: the longest path through the activity network, which sets the shortest possible project duration.
- **Total float**: the amount of time an activity can be delayed without delaying the project finish date.
- **Crashing**: shortening an activity's duration by adding resources, usually at extra cost.
- **Milestone**: a significant point or event in a project that has zero duration.

## The critical path method

Activities on the critical path have zero total float, so any delay to them delays the whole project. To shorten a project, managers crash critical activities first, choosing the one with the lowest crash cost per day. Crashing a non-critical activity costs money but does not shorten the project.

## Three-point estimates

When durations are uncertain, PERT uses three estimates for each activity: optimistic, most likely and pessimistic. The expected duration is the optimistic estimate plus four times the most likely estimate plus the pessimistic estimate, all divided by six.

## Earned value

- **Earned value**: the budgeted cost of the work actually completed so far.
- **Schedule variance**: earned value minus planned value; a negative value means the project is behind schedule.
- **Cost variance**: earned value minus actual cost; a negative value means the project is over budget.
