Course Compass

Ask questions and take a quiz grounded only in your own notes, with citations to the exact chunk.

Local demo, no AI model. Everything runs in this page: keyword (TF-IDF) retrieval, verbatim quotes, and template quiz questions. Nothing is uploaded and no API key is used. The full Python tool can optionally call an LLM with your own key.

Each question is built from one definition in your notes. The three wrong options are real terms from your other definitions, never invented.
